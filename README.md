# 🧊 Iceberg Radar

Daily tech / innovation / geopolitics report.
Mental model: **iceberg spotting** — disruptive tech and geopolitical events
as icebergs that startups need to steer clear of.

## Read the reports

→ **<https://humanity-plus.github.io/iceberg-radar/>**

Each day produces:

- `reports/YYYY-MM-DD.html` — full styled report
- `reports/YYYY-MM-DD.md` — markdown twin

## Sections

- 🧊 Iceberg Watch — disruptive tech & big-platform shifts
- 🚀 Innovation Pulse — frontier R&D, biotech, energy, robotics
- 💸 Startup & Capital — funding, IPOs, launches, M&A
- 🌍 Macro & Geopolitics — civilization, polycrisis, regulation
- 👀 Watch List — interesting but lower-priority signal

## How it's generated

Generated by an automated pipeline that scans curated blogs and feeds
(see source roster), scores items via a transparent heuristic model, and
renders deterministic HTML + Markdown. Reports are pushed here after each run.
